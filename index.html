Happy Burger - Order Management and Tracking System

Welcome to the Happy Burger Web-Based Order Management and Tracking System guide page.

Applications

  • Customer App - Browse menu, add items to cart, place orders, and track order status.
  • Admin App - View, manage, and update order statuses (Login is UI-only: enter any Staff ID and PIN).

Overview & Instructions

This project is an entirely frontend application built using HTML, CSS, and Vanilla JavaScript with no backend server or database.

  • Both applications share data locally using the browser's localStorage.
  • For real-time testing, open both the Customer App and the Admin App in separate tabs of the same browser window.
  • Orders placed in the Customer App will be visible in the Admin App. Status updates made in the Admin App will reflect in the Customer App.
